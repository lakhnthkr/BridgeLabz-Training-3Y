
Q1. Frontend, Backend and Full-Stack Development

Frontend:
Frontend is the part of a website that users can see and use.
It includes buttons, images, forms, text and website pages.

Example:
In an online shopping website, the product page and shopping
cart are part of the frontend.

Backend:
Backend is the part that works behind the website.
It handles data, login and other server-side work.

Example:
When a user logs in, the backend checks the username and password.

Full-Stack:
Full-stack means working on both frontend and backend.

Example:
A full-stack developer can create website pages as well as
the server-side part of the application.

        ^                    |

                 Response

The client is the user's browser.
It sends a request to the server.
The server processes the request and sends a response back.
The browser then shows the result to the user.


Q3. How a Browser Displays a Web Page

1. The user enters a website address in the browser.
2. The browser sends a request to the web server.
3. The web server receives the request.
4. The server sends the required web page back.
5. The browser receives the HTML, CSS and JavaScript files.
6. The browser processes these files.
7. Finally, the web page is displayed to the user.

Q5. What is a Web Server?

A web server receives requests from users and sends the required
web pages or data back to them.

Common examples of web servers are:

1. Apache
2. Nginx
3. Microsoft IIS
4. LiteSpeed
5. Node.js


Q6. Roles in a Project

Frontend Developer:
A frontend developer creates the part of a website that users
can see and interact with.

Backend Developer:
A backend developer creates the server-side part of the application.
They handle requests, data and application logic.

Database Administrator:
A database administrator manages and maintains the database.
They also take care of data security and backups.

Q8. Static and Dynamic Websites

Static Website:
A static website shows fixed content.
The content usually remains the same for every user.

Example:
A simple personal portfolio website.

Dynamic Website:
A dynamic website can change its content based on the user
or data from a database.

Example:
An online shopping website.

Main Difference:
A static website usually has fixed content, while a dynamic
website can display different or changing content.


Q9. Five Web Browsers and Rendering Engines

1. Google Chrome
   Rendering Engine: Blink

2. Mozilla Firefox
   Rendering Engine: Gecko

3. Safari
   Rendering Engine: WebKit

4. Microsoft Edge
   Rendering Engine: Blink

5. Opera
   Rendering Engine: Blink

A rendering engine is used by a browser to read HTML and CSS
and display a web page.

Different browsers can use different rendering engines.
Therefore, sometimes a web page can look slightly different
in different browsers.


Q10. Basic Web Architecture

             +-------------+
             |   CLIENT    |
             |   Browser   |
             +------+------+
                    |
                    | Request
                    v
             +-------------+
             |   SERVER    |
             +------+------+
                    |
           +--------+--------+
           |                 |
           v                 v
      +---------+       +----------+
      |   APIs  |       | DATABASE |
      +---------+       +----------+
           |                 |
           +--------+--------+
                    |
                    | Response
                    v
             +-------------+
             |   CLIENT    |
             | Displays    |
             |  Web Page   |
             +-------------+

The client sends a request to the server.
The server processes the request.

The server can communicate with APIs and the database
to get the required data.

Finally, the server sends the response back to the client,
and the browser displays the result.
